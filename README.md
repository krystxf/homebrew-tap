# krystxf/tap

Homebrew formulae by [krystxf](https://github.com/krystxf).

```sh
brew install krystxf/tap/pop-mac
brew install krystxf/tap/wtw
```

| Formula | Description |
| --- | --- |
| [`pop-mac`](Formula/pop-mac.rb) | [Pop Mac](https://github.com/krystxf/pop_mac): the Pop!_OS Shell tiling window manager for macOS |
| [`wtw`](Formula/wtw.rb) | [worktree-workflow](https://github.com/krystxf/worktree-workflow): a TUI tool for managing git worktrees |

`wtw.rb` is generated by GoReleaser when worktree-workflow is released. Change its
`.goreleaser.yml` rather than the formula.
